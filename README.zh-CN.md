# GuitarRig

[English](README.md) | 简体中文

GuitarRig 是一款 Blender 插件，用于将吉他演奏的手臂动作烘焙到已完成动捕的角色上。只需提供一个已播放动捕动画的角色和一个吉他模型，插件即可将吉他挂载在角色胸前，使按弦手贴合指板、拨弦手保持在琴弦上方，并将结果烘焙为新的动作（Action）。你原有的动画不会被修改。

本插件移植自 XR Animator / System Animator Online（SAO）的吉他系统，以离线逐帧求解替代实时解算：
- 吉他挂载在上胸部。
- 琴颈朝按弦手方向摆动。
- 双手手腕通过吉他上的直线和平面（“磁铁”）进行吸附牵引或阻挡限位。

**环境要求：**
- Blender 4.2 或更高版本（测试环境为 Blender 5.2）。
- 已完成动捕重定向的人形骨架，能够通过动作、NLA 或约束播放动捕动画。手指骨骼有助于提升效果，但非必需。
- 吉他类网格模型：包含琴体、较窄的琴颈和琴头。

**暂不包含：**
- 动捕重定向。
- 真实品格与琴弦的精确指法。
- 左利手演奏（已在计划中；当前仅求解右利手演奏）。
- 实时运行。

## 安装

以 Blender 扩展（Extension）的形式安装本插件：
1. 使用 `blender --command extension build --source-dir guitar_rig` 构建扩展包，或直接使用已打包好的扩展文件。
2. 在 Blender 中打开 **编辑 > 偏好设置 > 获取扩展（Edit > Preferences > Get Extensions）**，选择 **从磁盘安装（Install from Disk）**。

安装后，插件位于 3D 视图侧栏（按 `N` 键展开）的 **吉他** 标签页中。

## 工作流

在完成上一步之前，后续面板会呈灰显状态或提示缺少的前置条件。

### 1. 角色（Character）

1. 在 **GuitarRig** 面板中，将已重定向的骨架选为 **角色**。
2. 点击 **骨骼 > 自动映射骨骼** 自动识别骨骼映射。支持以下命名规范：
   - VRoid/VRM；
   - Mixamo；
   - Rigify（生成的骨骼、变形骨骼与 metarig 命名）；
   - MMD（日文骨骼名）；
   - Unreal Mannequin（UE4 与 UE5）。
3. 检查骨骼映射：
   - **胸骨（挂载）** 是悬挂吉他的骨骼，如果有上胸骨请优先选用。
   - **IK 链** 组中是受 IK 驱动的骨骼。对于 Rigify 风格的绑定，这里应填写 FK 控制器。
4. 点击 **校准 > 校准**。叠加层会在臀部、胸部和双手处绘制角色坐标系：
   - 红色表示角色左侧；
   - 绿色表示上方；
   - 蓝色表示前方。

   如果前方箭头指向背后，请勾选 **翻转朝向**。

### 2. 预处理（Prep，可选）

动捕采集与滤波往往会抹平一部分演奏表现力：拨弦手臂几乎不摆动，扫弦幅度偏小偏慢，按弦手指的按压与抬起也偏迟缓。**预处理** 会在烘焙前润色动捕数据以恢复这些细节。它只需已校准的角色而无需吉他模型，因此你可以直接在裸角色上评估效果。

当前版本支持使用 MMD Tools 导入的 MMD 模型（通过日文骨骼名查找骨骼）以及右利手演奏。

1. 在 **预处理** 面板中设置 **强度**。它会统一缩放所有工具的效果，0 表示不生效，大于 1 则超过默认强度。各工具的单独强度可在 **工具** 子面板中调整。
2. 点击 **应用预处理**。插件会读取你的原始动捕，并将结果写入 **GuitarPrep** NLA 图层；按 `Esc` 可取消。报告会给出处理前后的拨弦手腕位移、手部转动速度以及手指按压耗时。
3. 拖动时间轴预览。勾选 **显示原始动作** 可静音该图层以进行前后对比。
4. 可反复修改参数并重新应用：应用预处理始终从原始动捕出发计算，效果强度不会叠加累积。

预处理工具说明：

| 工具 | 作用 | 默认值 |
|---|---|---|
| 幅度 | 放大动作中的快速细节同时保留整体姿态：包括拨弦手相对于前臂的转动，以及每根按弦手指的关节动作。快速按弦会产生轻微过冲。 | 拨弦手腕 ×1.5，按弦手指 ×1.3，高于 1 Hz |
| 锐化 | 使每次动作过渡更干脆，同时保持起止位置与过半时刻不变：作用于拨弦动作与按弦手指的按压。**拨弦手指** 选项可同步锐化拨弦手的手指动作，适用于指弹。 | 拨弦动作 2，按弦手指 2，拨弦手指关 |
| 摆臂 | 为扫弦添加手臂摆动：手腕跟随拨片点的扫弦轨迹，通过肩部和肘部转动实现，且手臂提前一帧引领动作。 | 1× 扫弦幅度，肘部占比 0.7 |
| 扭转分配 | 将双手手腕的前臂自旋转移到前臂扭转骨骼（手捩）上，使前臂蒙皮正常扭转，同时手部姿态保持不变。 | 开启 |

按弦手指的活动范围会限制在原动捕范围加上 **关节余量**（5°）以内。

求解和烘焙会将 GuitarPrep 图层视为动捕输入。如果你在烘焙之后再次应用预处理，报告和面板会提示你重新烘焙。**移除预处理**（垃圾桶图标）会移除预处理图层，但保留已有的烘焙结果。

### 3. 吉他（Guitar）

1. 选中吉他网格（或其父级空物体），点击 **吉他 > 规范化坐标系**。
   - 插件会创建 `GTR_ROOT` 空物体（+X 沿琴颈指向琴头，+Z 垂直琴弦向外），并将吉他设为它的子级。
   - 如果模型并非真实尺寸，可在操作调整面板中设置 **真实长度**。
2. 在面板或视图中检查坐标轴方向。如果琴头或琴弦朝向相反，请点击 **翻转 X** 或 **翻转 Z**。
3. 选择与你的乐器最接近的[预设](#预设)，点击 **加载预设**。它将一并放置标定点、磁铁、挂载估计值以及瞄准和手腕设置。
4. 点击 **标定点 > 自动放置**（参见[自动放置标定点](#自动放置标定点)）。当没有与你吉他完全匹配的预设时（例如给电吉他加载了木吉他预设，或琴颈有倾角），强烈建议执行此步骤。
5. 检查标定点。点击列表中的条目可选中对应的空物体；若缺失则会在 3D 游标处添加。可根据需要手动移动或旋转这些空物体。对于平面类标定点，空物体的局部 Z 轴即为平面法线。

### 4. 挂载与手腕（Mount and wrist）

1. 切换到角色以典型姿势持琴的一帧。
2. 点击 **放置到挂载位**，移动并旋转 `GTR_ROOT` 使吉他准确贴合身体，然后点击 **捕获挂载**。此步骤为必填项：预设中的挂载位置仅作初始估计。
3. （可选）摆出一个理想的按弦手型帧，点击 **手腕 > 捕获手腕偏移**。**手腕混合** 用于控制按弦手腕采用该旋转目标的比例。

### 5. 求解与微调（Solve and tune）

1. 点击 **求解 > 构建绑定**。它会在双臂上添加 IK 和旋转约束，并在 `GuitarRig` 集合中生成辅助空物体。这些约束默认关闭，因此原有动画会照常播放。
2. 切换到有问题的帧并点击 **求解当前帧**。双臂会展示当前帧的求解结果，直到切换帧为止；点击 **显示动捕** 可立即关闭展示。
   - 视图叠加层会显示每个磁铁及其牵引距离。
   - 面板会列出双手手腕的移动距离以及生效的磁铁。
3. 选择 **模式**：
   - **跟随**（SAO 默认模式）：吉他朝按弦手方向摆动。
   - **对齐**（SAO 的 `Alt+A` 模式）：吉他保持在胸前不动，按弦手沿指板边缘滑动。

   使用 **区间覆盖** 可让指定帧范围改用另一种模式求解。
4. 如有需要，可在 **磁铁** 面板中微调磁铁参数。若手部穿模进入躯干，请开启 **胸部碰撞体**。

### 6. 烘焙与精修（Bake and refine）

1. 点击 **烘焙**。插件会逐帧求解范围内的每一帧并显示进度条；按 `Esc` 取消且不会改动场景。烘焙报告会给出：
   - 烘焙速度；
   - 最大的手腕修正距离；
   - 未收敛或 IK 未到达目标的帧；
   - 回放关键帧与求解结果之间的最大误差。
2. 在 **诊断** 面板中检查最差帧。修正对应问题（标定点、磁铁、模式区间）后重新烘焙。
3. 可选的后处理步骤：
   - **平滑** 对烘焙结果进行低通滤波：默认手臂为 6 Hz、吉他为 3 Hz。在 **修正量** 模式（默认）下，只平滑求解对手臂产生的改变量，从而保留动捕与预处理原有的快速动作；**关键帧** 模式则直接平滑手臂关键帧本身。
   - **重新限位** 会将平滑后进入阻挡面或胸部碰撞体的手部重新推回安全区域，仅重写受影响帧的关键帧。
4. 在 **GuitarRefine** NLA 图层上进行手动精修：
   - 和弦手型与按弦手指；
   - 手腕绕琴颈的扭转；
   - 扫弦重音与触弦细节。
5. **移除烘焙**（垃圾桶图标）会完整还原烘焙所做的所有修改；包含关键帧的精修动作会被保留。

## 烘焙写入的内容

在角色骨架和 `GTR_ROOT` 上，NLA 轨道从下到上依次为：
- 你原有的轨道（当前活动动作会被下推至独立轨道）；
- **GuitarPrep**（仅角色，执行应用预处理后生成）：润色后的通道，混合模式为替换（Replace），烘焙范围内每帧一个关键帧；
- **GuitarBake**：求解后的手臂骨骼链或吉他变换，混合模式为替换（Replace），每帧一个关键帧；
- **GuitarRefine**：空的合并（Combine）图层，供你做手动精修。重新烘焙时仅替换 GuitarBake，你的精修内容会完整保留。

手臂关键帧通道：
- 每侧手臂已映射的三根骨骼（上臂、前臂、手）始终会写入旋转关键帧，沿用各自原有的旋转模式。
- 它们之间的扭转骨骼仅在求解确实旋转了它时才会打帧。
- 位置与缩放仅在发生变化时才会打帧。

**吉他关键帧** 控制吉他的打帧空间：
- **胸骨**（默认）：将 `GTR_ROOT` 设为胸骨的子级并相对于胸骨打帧，后续修改身体动作时吉他会自动跟随。
- **世界空间**：在世界空间中直接为吉他打帧。

## 预设

每个预设均取材自 SAO 的对应吉他场景并保留了原始参数：标定点、磁铁、挂载估计值以及瞄准和手腕设置。点击 **加载预设** 会将标定点按比例适配到你的吉他琴颈和琴体上。

| 预设 | SAO 场景文件 | 差异说明 |
|---|---|---|
| 木吉他（Acoustic Guitar） | `scene.json` | 默认预设 |
| 电贝斯（Bass Guitar） | `scene - bass guitar.json` | 挂载位置低约 2 cm，且绕角色左右轴多旋转 10° |
| Stratocaster 电吉他（Stratocaster） | `scene - stratocaster guitar.json` | 挂载方式与电贝斯相同 |
| 尤克里里（Ukulele） | `scene - ukulele.json` | 挂载位置更靠近胸口中心约 6 cm 且多侧倾 10°；配有延伸至琴颈上方、长 26 cm 的扫弦线；包含上弦枕阻挡面 |

四个预设的磁铁参数相同，区别在于标定点在各自道具上的位置。测试套件会将每个预设与其对应的场景文件逐项核对。

在 SAO 的电吉他和电贝斯模型上，即使执行了自动放置，Stratocaster 电吉他与电贝斯预设的扫弦线位置也比木吉他预设更贴近 SAO 原始设置。仅执行加载预设时，它们放置的琴颈/琴体阻挡面与 SAO 误差在 1 cm 以内；而自动放置会将其移至琴踵处（在这些吉他上与前者相距 2–3 cm）。

尤克里里预设是唯一带有上弦枕阻挡面（Nut Barrier）标定点的预设。当你加载其他预设并同时替换磁铁时，加载预设会清理掉未被任何磁铁使用的上弦枕阻挡面。

## 标定点

标定点是位于 `GTR_ROOT` 下的空物体。每个标定点在自定义属性 `gtr_role` 中记录其角色，供磁铁和琴颈瞄准读取。

| 标定点 | 放置位置 | 用途 |
|---|---|---|
| 琴颈枢轴（Neck Pivot） | 指板下缘（−Y）靠近琴体处 | 琴颈瞄准轴起点 |
| 上弦枕（Nut） | 上弦枕处的指板下缘 | 琴颈瞄准轴终点 |
| 指板平面（Fretboard Plane） | 指板表面，法线 +Z | 按弦手吸附到该平面 |
| 指板边缘（Fretboard Edge） | 穿过指板下缘，法线 +Y | 按弦手保持在该边缘上方 |
| 琴颈/琴体阻挡面（Neck/Body Barrier） | 琴颈下方琴体起始处，法线 +X | 限制按弦手腕停留在琴颈区域 |
| 上弦枕阻挡面（Nut Barrier，可选） | 上弦枕附近，法线 −X | 防止按弦手腕滑向琴头（尤克里里预设） |
| 扫弦线 A/B（Strum Line A/B） | 扫弦线的琴体端与琴颈端 | 将拨弦手腕牵引到该线段 |
| 扫弦位置（Strum Position） | 位于扫弦线 A，法线 +X | 控制拨弦手沿琴弦方向的位置 |
| 琴弦平面（String Plane） | 琴弦上方，法线 +Z | 使拨弦指尖保持在琴弦平面上方 |

部分标定点的位置是与磁铁参数联合调校的约定值，并不直接对应网格几何表面：
- 琴弦平面位于指板上方约 4 cm，其磁铁的 **指尖偏移**（−4 cm）正好抵消这段高度。
- 扫弦线约束的是手腕位置，而非拨片位置。

### 自动放置标定点

**自动放置** 会测量 `GTR_ROOT` 下的吉他几何特征：
- 上弦枕位置；
- 琴踵（琴颈下方琴体开始的位置）；
- 指板顶面轮廓线（包含倾角）；
- 琴颈下缘与中心线；
- 琴体长度。

随后，插件会参照所选预设在其参考吉他上各标定点与上述特征的相对关系，将标定点放置到你的吉他上。这既保留了预设的约定（如琴弦平面高度、扫弦线偏移），又能与磁铁参数保持一致。该操作不会移动 `GTR_ROOT`，且在预设自带参考吉他上能精确还原预设点位。

与 **加载预设** 的基础适配相比：
- **琴颈/琴体阻挡面**：放置在琴踵处。在带缺角的吉他上，加载预设的基础适配会将其放在琴颈收窄处，可能向琴头方向偏移多达 10 cm。
- **指板相关平面**：会贴合指板的实际倾角。
- **扫弦线**：保持相对于琴踵的琴体长度比例。在木吉他上，这会使其准确落在音孔处。

测试套件使用木吉他预设，在 SAO 的五把吉他上将自动放置与 SAO 手动标定的点位进行了对比：
- **阻挡面**：误差在 2 cm 以内。
- **琴颈线**：误差约 1 cm 以内（与 SAO 自身点位的离散程度相当）。
- **扫弦线**：误差在 8 cm 以内，优于基础适配。SAO 的扫弦线长度在 9–26 cm 之间且因琴而异。

在每把 SAO 吉他上使用其对应预设时，自动放置可将所有标定点控制在距 SAO 原始点位 2 mm 以内。

自动放置会报告置信度及提示信息：
- **高**：成功检测到琴颈、琴踵与琴体。
- **中**：琴颈下方未检测到琴体、所选预设尚未包含琴踵测量数据，或吉他比例较为特殊。
- **低**：吉他坐标系本身存在疑点。

完成后请务必复查标定点。执行规范化、翻转或加载预设后会重新按基础适配放置标定点，因此在这些操作之后需再次运行自动放置。

## 磁铁

磁铁是位于吉他上、作用于单侧手腕的直线或平面。磁铁按列表顺序依次生效。

| 设置 | 含义 |
|---|---|
| 距离 (m) | 磁铁在按臂长缩放前的作用距离。阻挡面同样需要此参数。 |
| 幂次 | 0：随距离线性衰减的牵引；1：在作用距离内完全吸附；−9 或更低：无牵引，仅作阻挡面。 |
| 可穿越 | 关闭时将平面变为阻挡面：位于平面后方的手会被限位推回平面上。 |
| 手部偏移 | 磁铁作用于手上的参考点：手腕本身、瞄准偏移点，或自定义偏移。 |
| 指尖 | 指尖 v2 会平移手部，使最低的选定指尖恰好落在平面上。**仅推离** 允许指尖将手推离平面，但绝不向平面拉近。 |
| 滤波 | 在烘焙时逐帧平滑磁铁的牵引。**旋转** 滤波会平滑手部绕吉他原点的角度。 |
| 滞回 | 吸附类磁铁在上一帧吸附住手部后，下一帧作用距离按此倍率扩大。 |

预设内置的磁铁（与 SAO 一致）：
- **右手**：扫弦线（Strum Line）、扫弦位置（Strum Position）与琴弦阻挡面（String Barrier）。
- **左手**：指板平面（Fretboard Plane）、琴颈/琴体阻挡面（Neck/Body Barrier）与指板边缘（Fretboard Edge）；尤克里里预设还额外包含上弦枕阻挡面（Nut Barrier）。

将手腕拉向直线的磁铁会压缩手腕偏离直线的距离，从而抵消掉大部分拨弦幅度。**直通**（位于磁铁面板中，默认对右手开启）可让手腕的快速动作穿过磁铁：磁铁仅作用于手腕相对于胸部的低速轨迹（默认低于 1 Hz），快速拨弦动作会叠加回结果上，再由阻挡面和胸部碰撞体推出穿模。按弦手需要被指板磁铁牢牢吸附，因此默认关闭。烘焙会先预读所有帧的手腕轨迹以计算直通细节；求解当前帧则会读取当前帧前后各 2 秒的帧。诊断曲线中记为 `R pass-through (cm)`。

**胸部碰撞体** 是包裹躯干的胶囊体，在磁铁生效前将双手手腕及指尖向前推出身体。默认关闭。

## 模式与区间覆盖

**模式** 按钮会像 SAO 的 `Alt+A` 一样同时切换琴颈瞄准与指板边缘磁铁：

| | 跟随（Follow） | 对齐（Align） |
|---|---|---|
| 琴颈瞄准 | 开启 | 关闭 |
| 指板边缘磁铁 | 阻挡面（幂次 −99），旋转滤波 | 吸附（幂次 1），无滤波 |

切换后各项参数仍可手动编辑。**区间覆盖** 允许指定帧范围采用特定模式求解：
- 区间会在场景设置的基础上，对其范围内的帧应用对应模式的切换。
- 当多个已启用的区间重叠时，列表中靠下的区间优先生效。
- 在模式切换处，烘焙会重置滤波器和滞回状态，琴颈瞄准权重会在 5 帧内平滑过渡。
- 求解当前帧使用相同的调度逻辑，因此预览结果与烘焙一致。
- 区间覆盖面板会显示当前帧的模式及过渡进度。

## 诊断

每次烘焙都会逐帧记录求解详情，并以动画自定义属性的形式打帧在 `GTR_Diagnostics` 空物体上。点击 **选择曲线** 并打开曲线编辑器即可查看。

| 曲线 | 含义 |
|---|---|
| `L`/`R wrist correction (cm)` | 碰撞体、磁铁和伸展限制将手腕目标从动捕手腕移动的距离 |
| `L`/`R IK miss (mm)` | 求解后的手腕与目标点之间的偏差 |
| `L`/`R chest collider (cm)` | 胸部碰撞体的推离距离（仅在开启碰撞体时记录） |
| `L`/`R pass-through (cm)` | 穿过磁铁的快速手腕位移（仅开启直通的手） |
| `L`/`R <magnet> d (cm)` | 手部参考点到磁铁的距离。平面带符号：负值表示位于平面后方 |
| `L`/`R <magnet> w` | 磁铁权重：1 表示完全吸附或阻挡限位 |
| `neck swing (°)`、`fretting wrist turn (°)` | 吉他琴颈摆动角度与按弦手腕转动角度 |
| `solve passes`、`settled` | 求解迭代轮数，以及瞄准与手腕是否收敛 |
| `mode (0 follow, 1 align)`、`neck aim weight` | 当前帧的模式与琴颈瞄准权重 |

**诊断** 面板会按所选指标列出最差的 5 帧，点击即可跳转定位。支持的指标包括：
- **手腕修正量**；
- **阻挡深度**：手部参考点在被限位前深入阻挡面的距离；
- **IK 偏差**；
- **琴颈摆动**；
- **手腕转动**；
- **胸部碰撞体**；
- **未收敛**。

诊断数据反映的是烘焙求解本身，不包含后续平滑或重新限位的结果。执行移除烘焙时会一并删除诊断数据。

## 故障排查

| 现象 | 排查方向 |
|---|---|
| “The IK misses its target”（IK 偏离目标） | 检查手臂骨骼是否存在 IK 锁定、限位或拉伸，或骨骼链长度不足 |
| “Played back, the bake is … mm from the solve”（回放与求解偏差较大） | 检查已烘焙的手臂骨骼或 `GTR_ROOT` 上是否叠加了其他约束、驱动器或 NLA 轨道 |
| 吉他迭代时来回抖动 | 调低 **松弛系数**，或调高 **迭代次数**（求解 > 选项） |
| “The neck aim was limited”（琴颈瞄准受限） | 按弦手距离琴颈过远。检查挂载位置，或调高 **最大摆角** |
| 手部穿透琴颈或琴体 | 检查标定点（指板平面、边缘、阻挡面）；重新烘焙，或在平滑后执行重新限位 |
| 吉他陷进躯干里 | 重新捕获挂载位置，或开启胸部碰撞体 |
| 角色坐标系箭头方向错误 | 使用 **翻转朝向**，或检查骨骼映射中的肩部与头部骨骼 |
| 翻转或加载预设后标定点跳回原位 | 这些操作会按预设基础适配重新放置标定点；请再次运行自动放置 |
| “Prep supports MMD models”（预处理仅支持 MMD 模型） | 预处理按 MMD 日文骨骼名（人指１、手捩等）查找骨骼；请使用 MMD Tools 导入模型 |
| 增强扫弦幅度后前臂严重扭曲 | 保持开启 **扭转分配到扭转骨**。若模型没有手捩骨骼，该功能会自动关闭，此时请调低拨弦手腕的幅度参数 |
| 平滑后预处理的扫弦动作消失 | 请使用平滑中的 **修正量** 模式，而非 **关键帧** 模式 |

## 开发者指南

GuitarRig 支持 Blender 原生翻译系统。添加或更新语言请参阅 [Translating GuitarRig](TRANSLATING.md)。语言目录位于 `i18n/locales/` 下，未翻译条目会自动回退到英文。界面语言遵循 Blender 的语言设置以及界面、工具提示和报告翻译偏好。

在插件根目录内通过 Blender 运行测试套件：

```
blender -b --factory-startup --python-exit-code 1 --python tests/run.py -- [-v] [-k PATTERN]
```

- 当 SAO 的 `guitar_collection_v9.1` 文件夹位于插件目录同级时，会运行与 SAO 对比的测试；否则自动跳过。
- 当环境变量 `GTR_TEST_PMX` 和 `GTR_TEST_VMD` 指向 MMD 模型与动作文件（核对数值需使用 `example.pmx` 和 `part1.vmd`）且已安装 MMD Tools 扩展时，会运行真实模型的预处理测试。
- `tools/measure_reference.py` 用于测量预设的参考道具，并写入预设的 `frame` 和 `reference` 字段。
- 代码结构如下：
  - `core/`：数学计算与求解核心，可脱离 UI 独立测试（`prep.py` 和 `prepjob.py` 为动捕预处理模块）；
  - `ops/`：操作器（Operators）；
  - `ui/`：面板、列表与视图叠加层；
  - `rig/`：辅助绑定构建；
  - `presets/`：乐器预设与骨骼命名规范。
